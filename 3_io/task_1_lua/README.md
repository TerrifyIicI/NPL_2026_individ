# Задача 3.1 — KV-хранилище с журналом на упаковке строк и корутинном обходе

**Тема:** 3. Ввод/вывод в консоль и файл  
**Язык программирования:** Lua  
**Ветка для реализации:** `3_task_1_lua`

## Общая задача темы

Задача темы: файловое KV-хранилище (ключ — значение) с журналом операций и уплотнением. Во всех четырёх реализациях используется общий формат журнала.

## Постановка задачи

Бинарные записи журнала пакуются и распаковываются средствами string.pack, индекс ключей хранится в обычной таблице, метатаблицы дают синтаксис обращения к базе как к массиву, а потоковый обход журнала при уплотнении реализуется корутиной — без загрузки гигабайтного файла в память. Главное измерение — накладные расходы рантайма: размер интерпретатора, время старта, память индекса на миллион ключей и скорость записи в одной таблице с Python и C++.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
