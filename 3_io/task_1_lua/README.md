# Задача 3.1. Файловое KV-хранилище с журналированием и восстановлением

**Тема:** Ввод/вывод в консоль и файл  
**Язык:** Lua  
**Ветка:** `3_task_1_lua`

## Постановка задачи

Консольное хранилище поддерживает добавление, чтение, изменение и удаление пар ключ–значение. Операции дописываются в журнал с контрольными суммами; при запуске восстанавливается индекс и отбрасывается оборванная последняя запись. Обход журнала реализуется корутиной, уплотнение сохраняет только актуальные значения.

## Входные данные

Путь к файлу журнала и консольные команды для операций с ключами.

## Выходные данные

Результаты команд, файл журнала и восстановленное состояние хранилища.

## Проверка корректности

Проверить добавление, изменение, удаление, восстановление после перезапуска, оборванную последнюю запись и уплотнение.
