# Задача 3.3. Постраничный просмотр больших лог-файлов с индексом строк

**Тема:** Ввод/вывод в консоль и файл  
**Язык:** Kotlin  
**Ветка:** `3_task_3_kotlin`

## Постановка задачи

Консольный просмотрщик строит разреженный индекс байтовых смещений начала строк большого текстового файла. Поддерживаются переход к номеру строки, следующая и предыдущая страницы, поиск текста. При чтении учитываются кодировка UTF-8 и последняя строка без завершающего перевода строки.

## Входные данные

Путь к лог-файлу, размер страницы и консольные команды навигации или поиска.

## Выходные данные

Запрошенные страницы с номерами строк и результаты поиска.

## Проверка корректности

Проверить переходы между страницами, поиск UTF-8-текста, пустой файл и последнюю строку без перевода строки.
