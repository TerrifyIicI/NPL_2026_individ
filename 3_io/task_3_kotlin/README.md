# Задача 3.3 — KV-хранилище с журналом на файловых каналах и байт-буферах JVM

**Тема:** 3. Ввод/вывод в консоль и файл  
**Язык программирования:** Kotlin  
**Ветка для реализации:** `3_task_3_kotlin`

## Общая задача темы

Задача темы: файловое KV-хранилище (ключ — значение) с журналом операций и уплотнением. Во всех четырёх реализациях используется общий формат журнала.

## Постановка задачи

Записи читаются и пишутся через файловый канал и байт-буфер с явным порядком байт, ресурсы закрываются конструкцией use, результат команды моделируется sealed-классом, потоковый обход при уплотнении — через sequence. Отдельная таблица посвящена цене виртуальной машины: время старта пустой программы, время первого прогона и выход на плато после прогрева, память при разных настройках кучи, а также сравнение двух файловых API и двух типов буферов между собой.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
