# Задача 3.2. Консольный редактор двоичных файлов с отменой изменений

**Тема:** Ввод/вывод в консоль и файл  
**Язык:** Odin  
**Ветка:** `3_task_2_odin`

## Постановка задачи

Программа показывает выбранные участки файла в шестнадцатеричном и текстовом представлении. Поддерживаются переход по смещению, замена байтов без изменения размера файла и отмена правок. Изменения сохраняются в отдельном выходном файле, исходный файл не изменяется; обработка выполняется без полной загрузки исходного файла в память.

## Входные данные

Путь к исходному и выходному файлам, смещения, байты для замены и команды просмотра или отмены.

## Выходные данные

Представление выбранных участков и изменённый выходной файл.

## Проверка корректности

Проверить редактирование начала и конца файла, отмену нескольких правок, недопустимое смещение и неизменность исходника.
