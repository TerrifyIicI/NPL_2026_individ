# Задача 3.2 — KV-хранилище с журналом на ручных буферах и собственной арене

**Тема:** 3. Ввод/вывод в консоль и файл  
**Язык программирования:** Odin  
**Ветка для реализации:** `3_task_2_odin`

## Общая задача темы

Задача темы: файловое KV-хранилище (ключ — значение) с журналом операций и уплотнением. Во всех четырёх реализациях используется общий формат журнала.

## Постановка задачи

Та же задача на уровне системного языка: явные срезы байт, defer, множественный возврат вместо исключений и три стратегии выделения памяти под индекс — штатный аллокатор, собственная арена и временный аллокатор для буферов разбора. Сравниваются пиковая память и время загрузки индекса против unordered_map в C++ и dict с его сборщиком мусора в Python. Проверочный тест — потоковое уплотнение журнала объёмом 1 ГБ при лимите памяти 128 МБ на данных, объём индекса которых допускает такой лимит.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
