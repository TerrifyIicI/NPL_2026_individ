# Задача 3.4 — То же хранилище на той же JVM в динамическом стиле — замер цены динамики

**Тема:** 3. Ввод/вывод в консоль и файл  
**Язык программирования:** Groovy  
**Ветка для реализации:** `3_task_4_groovy`

## Общая задача темы

Задача темы: файловое KV-хранилище (ключ — значение) с журналом операций и уплотнением. Во всех четырёх реализациях используется общий формат журнала.

## Постановка задачи

Та же программа, та же JVM, та же стандартная библиотека и тот же формат файла — но в динамическом стиле: обращение к базе через перегрузку операторов индексирования, команды через methodMissing, работа с потоками через замыкания. В сопоставимых условиях оцениваются накладные расходы динамической диспетчеризации; измеряются три режима (динамическое исполнение, проверка типов и статическая компиляция) в одной таблице с Kotlin. При интерпретации учитываются также различия в реализации и прогреве JVM.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
