# Задача 3.4. Пакетное переименование файлов с предварительным просмотром и отменой

**Тема:** Ввод/вывод в консоль и файл  
**Язык:** Groovy  
**Ветка:** `3_task_4_groovy`

## Постановка задачи

Программа формирует план переименования файлов в каталоге по заданному шаблону. Перед выполнением показывается предварительный результат и проверяются конфликты имён. Выполненные переименования записываются в журнал, по которому доступна отдельная операция отмены. Циклические переименования выполняются через временные имена или отклоняются с диагностикой; существующие файлы не перезаписываются.

## Входные данные

Путь к каталогу, шаблон переименования и команда предварительного просмотра, выполнения или отмены.

## Выходные данные

План переименований, новые имена файлов и журнал операций.

## Проверка корректности

Проверить обычное переименование, конфликт имён, отмену и отсутствие изменений при предварительном просмотре.
