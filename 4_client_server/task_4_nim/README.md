# Задача 4.4. Асинхронный поисковый сервер по коллекции текстовых документов

**Тема:** Клиент-серверное взаимодействие  
**Язык:** Nim  
**Ветка:** `4_task_4_nim`

## Постановка задачи

При запуске сервер строит инвертированный индекс локальной коллекции текстовых документов. Клиенты отправляют запросы из нескольких слов и получают список документов, содержащих все указанные слова. Соединения обслуживаются асинхронно с использованием `async`/`await`. Индекс строится самостоятельно, без готового поискового движка.

## Входные данные

Каталог текстовых документов, адрес и порт сервера, поисковые запросы.

## Выходные данные

Список подходящих документов для каждого запроса.

## Проверка корректности

Проверить запросы из одного и нескольких слов, отсутствие результатов и параллельное обслуживание нескольких клиентов.
