# Задача 4.4 — KV-сервер с подпиской на компилируемом async с переключаемым сборщиком мусора

**Тема:** 4. Клиент-серверное взаимодействие  
**Язык программирования:** Nim  
**Ветка для реализации:** `4_task_4_nim`

## Общая задача темы

Задача темы: сетевое KV-хранилище с подпиской на изменения. Для всех вариантов определяется общий протокол взаимодействия.

## Постановка задачи

Тот же сервер реализуется на `async`/`await` с циклом событий и асинхронными операциями ввода-вывода. При сравнении с Python `asyncio` учитываются различия рантаймов и реализации, а не только компиляции и интерпретации. Вторым экспериментом для выбранной версии Nim сравниваются доступные режимы управления памятью; при высокой нагрузке измеряются память и высокие перцентили задержки.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
