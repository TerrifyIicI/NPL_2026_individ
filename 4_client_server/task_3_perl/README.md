# Задача 4.3 — KV-сервер с подпиской на ручном мультиплексоре без async/await

**Тема:** 4. Клиент-серверное взаимодействие  
**Язык программирования:** Perl  
**Ветка для реализации:** `4_task_3_perl`

## Общая задача темы

Задача темы: сетевое KV-хранилище с подпиской на изменения. Для всех вариантов определяется общий протокол взаимодействия.

## Постановка задачи

Сервер пишется как однопоточный цикл опроса дескрипторов с ручными буферами на каждое соединение и ручной досборкой строк — с явным управлением неблокирующим вводом-выводом. Сравнение с эталоном на asyncio и с Nim-версией разбивается по строкам кода отдельно на досборку сообщений и на управление состоянием соединения: так видно, сколько именно кода прячут async и await и сколько это стоит по скорости. Отдельно строится график изменения производительности опроса дескрипторов при росте числа соединений и изучаются ограничения выбранного механизма в сравнении с `epoll`.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
