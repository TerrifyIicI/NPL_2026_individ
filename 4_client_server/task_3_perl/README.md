# Задача 4.3. Передача файлов с докачкой после разрыва соединения

**Тема:** Клиент-серверное взаимодействие  
**Язык:** Perl  
**Ветка:** `4_task_3_perl`

## Постановка задачи

Клиент скачивает файл из разрешённого каталога сервера и сохраняет незавершённую загрузку. После повторного подключения передача продолжается с подтверждённого смещения. Проверяются размер и контрольная сумма результата, отдельно обрабатываются изменение исходного файла и неверное смещение докачки. Сервер не предоставляет доступ к файлам за пределами разрешённого каталога.

## Входные данные

Адрес сервера, имя файла, локальный путь и сведения о незавершённой загрузке.

## Выходные данные

Загруженный файл с проверенным размером и контрольной суммой либо диагностическое сообщение.

## Проверка корректности

Прервать загрузку и возобновить её; проверить неверное смещение, изменение исходника и попытку выхода за пределы каталога.
