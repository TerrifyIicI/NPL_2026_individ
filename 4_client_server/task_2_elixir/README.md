# Задача 4.2 — KV-сервер с подпиской на процессах, реестре подписок и супервизорах

**Тема:** 4. Клиент-серверное взаимодействие  
**Язык программирования:** Elixir  
**Ветка для реализации:** `4_task_2_elixir`

## Общая задача темы

Задача темы: сетевое KV-хранилище с подпиской на изменения. Для всех вариантов определяется общий протокол взаимодействия.

## Постановка задачи

На каждое соединение заводится процесс, подписки хранит реестр, состояние — сервер-процесс, обработчики живут под супервизором. Сценарий с 10 000 соединений служит витриной рантайма: замеряется память на одно соединение против потоков ОС в C++ и корутин в Python. В режиме отказов часть обработчиков принудительно завершается при идущей нагрузке; строится график изменения пропускной способности и измеряется время восстановления. Вторая версия хранилища на таблице с параллельным чтением сравнивается с сериализующим всё сервером-процессом.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
