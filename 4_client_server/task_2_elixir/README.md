# Задача 4.2. Сервер учебных аукционов с дедлайнами и защитой от повторных запросов

**Тема:** Клиент-серверное взаимодействие  
**Язык:** Elixir  
**Ветка:** `4_task_2_elixir`

## Постановка задачи

Сервер позволяет создавать учебные аукционы, отправлять ставки и получать состояние лота. По серверному дедлайну торги закрываются и определяется победитель. Идентификаторы запросов предотвращают повторную обработку одной ставки при повторной отправке клиентом. Состояние каждого аукциона обновляется последовательно серверным процессом.

## Входные данные

Команды создания аукциона, ставки с идентификаторами запросов, запросы состояния и дедлайн.

## Выходные данные

Состояние лота, подтверждения или отклонения ставок, результат завершившегося аукциона.

## Проверка корректности

Проверить конкурирующие ставки, повторную отправку запроса, ставку после дедлайна и определение победителя.
