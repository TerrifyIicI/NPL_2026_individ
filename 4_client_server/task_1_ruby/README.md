# Задача 4.1. Сетевое KV-хранилище с подписками на изменения ключей

**Тема:** Клиент-серверное взаимодействие  
**Язык:** Ruby  
**Ветка:** `4_task_1_ruby`

## Постановка задачи

TCP-сервер поддерживает чтение, изменение и удаление значений, а также подписку на изменения ключей. После изменения сервер отправляет уведомления подписчикам; при отключении клиента его подписки удаляются. Основная модель обработки соединений — поток на клиента с синхронизацией общего состояния. Цикл событий с мультиплексированием может быть реализован как дополнительный вариант.

## Входные данные

Адрес и порт сервера, клиентские команды чтения, записи, удаления и подписки.

## Выходные данные

Ответы на команды и уведомления об изменениях ключей.

## Проверка корректности

Проверить одновременные подключения, уведомления нескольких подписчиков, удаление ключа и очистку подписок при отключении.
