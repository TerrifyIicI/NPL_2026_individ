# Задача 2.1. Рекурсивный движок регулярных выражений с возвратом

**Тема:** Алгоритмические задачи  
**Язык:** Prolog  
**Ветка:** `2_task_1_prolog`

## Постановка задачи

DCG-грамматика разбирает шаблон регулярного выражения в дерево. Поддерживаются литералы, точка, группировка, альтернатива и квантификаторы `*`, `+`, `?`. Рекурсивный матчер с возвратом находит вхождения в тексте и выводит их позиции. Для повторений предусмотрена проверка продвижения по тексту, исключающая бесконечную рекурсию при пустых совпадениях.

## Входные данные

Шаблон регулярного выражения и текст.

## Выходные данные

Позиции начала и конца найденных совпадений.

## Проверка корректности

Проверить литералы, альтернативы, вложенные группы, квантификаторы, отсутствие совпадений и повторения выражений, допускающих пустое совпадение.
