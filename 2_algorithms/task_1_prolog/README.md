# Задача 2.1 — Движок регулярных выражений на DCG-грамматике со встроенным бэктрекингом (рекурсия)

**Тема:** 2. Алгоритмические задачи  
**Язык программирования:** Prolog  
**Ветка для реализации:** `2_task_1_prolog`

## Общая задача темы

Задача темы: реализация собственного движка регулярных выражений. Для всех вариантов определяется общее подмножество синтаксиса и набор тестов.

## Постановка задачи

Шаблон разбирается DCG-грамматикой в дерево, а перебор альтернатив и откат при неудаче выполняются средствами поиска Prolog без собственного стека бэктрекинга. Объём кода сравнивается с реализацией явного поиска на C++. Жадность и ленивость квантификатора задаются порядком клауз, обе версии демонстрируются. Отдельно сравниваются три режима на тесте катастрофического бэктрекинга: без таблиц, с табличными вычислениями (`table`, если поддерживаются выбранной реализацией Prolog) и с ручной мемоизацией через `assertz`.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
