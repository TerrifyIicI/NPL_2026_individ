# Задача 2.3 — Движок регулярных выражений на самописных парсер-комбинаторах и ленивых списках (рекурсия)

**Тема:** 2. Алгоритмические задачи  
**Язык программирования:** Haskell  
**Ветка для реализации:** `2_task_3_haskell`

## Общая задача темы

Задача темы: реализация собственного движка регулярных выражений. Для всех вариантов определяется общее подмножество синтаксиса и набор тестов.

## Постановка задачи

Парсер шаблона собирается из комбинаторов, написанных с нуля: объявляются инстансы Functor, Applicative, Alternative и Monad, после чего квантификаторы * и + берутся из many и some бесплатно. Матчер возвращает ленивый список всех успешных разборов, поэтому режимы «первое вхождение» и «все вхождения» — один и тот же код; различия оцениваются по профилю выполнения, включая затраты памяти. Вторая версия на `ByteString` (базовый пакет экосистемы GHC, не готовый движок регулярных выражений) используется для сравнения со `String` на корпусе в 50 МБ.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
