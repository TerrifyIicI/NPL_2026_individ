# Задача 2.3. Решение задачи выполнимости булевых формул алгоритмом DPLL — рекурсия

**Тема:** Алгоритмические задачи  
**Язык:** Haskell  
**Ветка:** `2_task_3_haskell`

## Постановка задачи

Программа читает булеву формулу в формате DIMACS CNF и проверяет её выполнимость алгоритмом DPLL. Рекурсивный поиск включает распространение единичных литералов, выбор переменной и возврат при противоречии. Выводится удовлетворяющий набор значений либо `UNSAT`.

## Входные данные

Файл DIMACS CNF.

## Выходные данные

Удовлетворяющее присваивание переменных либо `UNSAT`.

## Проверка корректности

Проверить выполнимую и невыполнимую формулы, пустую формулу и формулу с пустой клаузой; подстановкой проверить найденное присваивание.
