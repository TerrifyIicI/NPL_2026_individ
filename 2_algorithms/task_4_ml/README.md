# Задача 2.4. Поиск кратчайшего пути на клеточной карте алгоритмом A*

**Тема:** Алгоритмические задачи  
**Язык:** Standard ML  
**Ветка:** `2_task_4_ml`

## Постановка задачи

По клеточной карте с препятствиями и положительной стоимостью прохода строится маршрут между двумя заданными точками. Используется алгоритм A*, перемещение разрешено в четырёх направлениях; эвристика — манхэттенское расстояние, умноженное на минимальную стоимость разрешённого шага. Выводятся маршрут, его стоимость и число обработанных состояний либо сообщение об отсутствии пути.

## Входные данные

Клеточная карта с препятствиями и стоимостями, начальная и конечная точки.

## Выходные данные

Маршрут, его стоимость и число обработанных состояний либо сообщение об отсутствии пути.

## Проверка корректности

Проверить карты с препятствиями, неодинаковыми стоимостями и без доступного пути; сравнить стоимость с алгоритмом Дейкстры на малых картах.
