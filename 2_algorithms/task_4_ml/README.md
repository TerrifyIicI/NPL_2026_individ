# Задача 2.4 — Два движка регулярных выражений под одной сигнатурой, подставляемые функтором (рекурсия)

**Тема:** 2. Алгоритмические задачи  
**Язык программирования:** ML (SML)  
**Ветка для реализации:** `2_task_4_ml`

## Общая задача темы

Задача темы: реализация собственного движка регулярных выражений. Для всех вариантов определяется общее подмножество синтаксиса и набор тестов.

## Постановка задачи

Объявляется сигнатура матчера, под неё пишутся две структуры — бэктрекинг и NFA Томпсона, — и обе подставляются в один и тот же функтор движка без единой правки вызывающего кода. На тестах с большим числом альтернатив сравнивается рост времени работы обеих реализаций (в том числе характерная экспоненциальная деградация бэктрекинга) и эталонов `re` и `std::regex`. Вторым экспериментом в тип узлов добавляется новый вариант, и в отчёт выписывается полный список мест, где компилятор потребовал дописать обработку, — против молчания Python на той же правке.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
