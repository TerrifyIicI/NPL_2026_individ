# Задача 2.2 — Движок регулярных выражений с бэктрекингом на продолжениях call/cc (рекурсия)

**Тема:** 2. Алгоритмические задачи  
**Язык программирования:** Scheme  
**Ветка для реализации:** `2_task_2_scheme`

## Общая задача темы

Задача темы: реализация собственного движка регулярных выражений. Для всех вариантов определяется общее подмножество синтаксиса и набор тестов.

## Постановка задачи

Тот же возврат, но собранный руками: матчер пишется в стиле передачи продолжений с явными success- и fail-замыканиями, вторая версия захватывает точки возврата через call/cc и складывает их в стек выборов. Гарантированная стандартом Scheme оптимизация хвостовых вызовов проверяется тестами вложенности шаблона с возрастающей глубиной (до 2000 при достаточных ресурсах); строится таблица глубины, потребления памяти и поведения аналогичных реализаций на Python и C++. В отчёте разбирается, какие вызовы матчера хвостовые, а какие ломает конкатенация узлов.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
