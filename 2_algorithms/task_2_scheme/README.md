# Задача 2.2. Символьное дифференцирование и упрощение выражений — рекурсия

**Тема:** Алгоритмические задачи  
**Язык:** Scheme  
**Ветка:** `2_task_2_scheme`

## Постановка задачи

Программа читает арифметическое выражение в префиксной записи и вычисляет его производную по указанной переменной. Поддерживаются сложение, вычитание, умножение, деление и степень с целым показателем. Рекурсивное упрощение выполняет свёртку констант и удаляет нейтральные операции, сохраняя корректность в области определения выражения.

## Входные данные

Выражение в префиксной записи и переменная дифференцирования.

## Выходные данные

Производная и её упрощённое представление в префиксной записи.

## Проверка корректности

Проверить производные константы, переменной, суммы, произведения, частного и степени, включая вложенные выражения.
