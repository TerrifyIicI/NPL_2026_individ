# Задача 5.3 — Конвертер JSON ⇄ NBF на вариантных типах с исчерпывающим сопоставлением

**Тема:** 5. Конвертация данных  
**Язык программирования:** OCaml  
**Ветка для реализации:** `5_task_3_ocaml`

## Общая задача темы

Задача темы: конвертация JSON ⇄ NBF, где NBF — собственный бинарный формат с единой спецификацией для всех четырёх программ.

## Постановка задачи

Значение описывается вариантным типом, разбор — взаимно-рекурсивными функциями, предупреждения о неполном сопоставлении настраиваются как ошибки компиляции. Главный эксперимент показывается вживую: в тип добавляется новый вариант, и исследуются сообщения компилятора о местах, где надо дописать обработку; та же модификация проводится в эталонах на Python и C++, чтобы сравнить диагностику и поведение при выполнении. Вторым экспериментом три кодировщика — бинарный, JSON и S-выражения — подставляются в один функтор под общей сигнатурой.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
