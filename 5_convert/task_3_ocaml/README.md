# Задача 5.3. Двусторонняя конвертация изображений PPM ⇄ QOI

**Тема:** Конвертация данных  
**Язык:** OCaml  
**Ветка:** `5_task_3_ocaml`

## Постановка задачи

Программа преобразует изображения PPM P6 с восьмибитными RGB-компонентами (максимальное значение компоненты 255) в QOI и обратно. Поддерживаются RGB-изображения без прозрачности; QOI с непрозрачностью, отличной от полной, отклоняется. Кодирование и декодирование реализуются самостоятельно, без готового графического кодека. Корректность проверяется совпадением размеров и значений пикселей после обратного преобразования.

## Входные данные

Файл PPM P6 или QOI без прозрачности и направление преобразования.

## Выходные данные

Изображение в целевом формате либо сообщение о неподдерживаемых или повреждённых данных.

## Проверка корректности

Сравнить размеры и RGB-пиксели после PPM → QOI → PPM; проверить одноцветное изображение, повторяющиеся пиксели и некорректный вход.
