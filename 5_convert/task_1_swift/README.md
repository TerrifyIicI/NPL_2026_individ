# Задача 5.1 — Конвертер JSON ⇄ NBF через собственный кодировщик для Codable

**Тема:** 5. Конвертация данных  
**Язык программирования:** Swift  
**Ветка для реализации:** `5_task_1_swift`

## Общая задача темы

Задача темы: конвертация JSON ⇄ NBF, где NBF — собственный бинарный формат с единой спецификацией для всех четырёх программ.

## Постановка задачи

Пишется не парсер, а собственный кодировщик и декодировщик для бинарного формата — реализуются протоколы кодирования из стандартной библиотеки, после чего любой тип, помеченный Codable, сериализуется в NBF без единой строки кода на тип. Демонстрация: доменная структура объявляется один раз и сразу пишется и в JSON штатным `JSONEncoder` из Foundation, и в NBF вашим, а добавление нового поля не требует правок ни в одном из них. В таблице это сопоставляется с обходом словаря атрибутов в Python и с необходимостью кодогенерации в C++, с указанием, где именно ошибка обнаруживается — при компиляции или в рантайме.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
