# Задача 5.1. Двусторонняя конвертация JSON ⇄ NBF с интернированием строк

**Тема:** Конвертация данных  
**Язык:** Swift  
**Ветка:** `5_task_1_swift`

## Постановка задачи

Программа преобразует JSON в собственный учебный бинарный формат NBF и обратно. Структура NBF документируется; повторяющиеся строки сохраняются в общей таблице и заменяются ссылками. Собственные кодировщик и декодировщик подключают NBF к моделям `Codable`; проверяются сохранность значений и обработка повреждённых данных. Поддерживаются JSON-объекты, массивы, строки, логические значения, `null` и числа в документированном диапазоне представимых типов. Для JSON допускается штатный Foundation, без API, доступных только на платформах Apple.

## Входные данные

JSON- или NBF-файл и направление преобразования.

## Выходные данные

Файл в целевом формате либо диагностика некорректных данных.

## Проверка корректности

Проверить вложенные структуры, повторяющиеся строки, пустые значения, числа в поддерживаемом диапазоне и обратное преобразование; отклонять повреждённый NBF.
