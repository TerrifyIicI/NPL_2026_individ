# Задача 5.2 — Конвертер JSON ⇄ NBF как композиция функций над персистентными данными

**Тема:** 5. Конвертация данных  
**Язык программирования:** Clojure  
**Ветка для реализации:** `5_task_2_clojure`

## Общая задача темы

Задача темы: конвертация JSON ⇄ NBF, где NBF — собственный бинарный формат с единой спецификацией для всех четырёх программ.

## Постановка задачи

JSON разбирается собственным парсером в обычные персистентные отображения и векторы, поэтому конвертер записывается как композиция чистых функций, а выбор кодирования — мультиметодами по типу значения. При добавлении третьего формата вывода измеряется объём изменений по сравнению с аналогичной правкой в C++. Отдельно измеряется цена персистентности: память и время разбора стомегабайтного файла в персистентных структурах, в их изменяемых аналогах, в словаре Python и в хеш-таблице C++. Четвёртым экспериментом один и тот же кодировщик пишется на мультиметодах и на протоколах — сравнение двух механизмов полиморфизма внутри одного языка.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
