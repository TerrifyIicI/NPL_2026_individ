# Задача 5.2. Преобразование календаря iCalendar в HTML-расписание

**Тема:** Конвертация данных  
**Язык:** Clojure  
**Ветка:** `5_task_2_clojure`

## Постановка задачи

Программа преобразует поддерживаемое подмножество iCalendar в HTML-расписание, отсортированное по времени начала событий. Поддерживаются одиночные события с временем UTC, названием и местом проведения, разворачивание перенесённых строк iCalendar и экранирование текста при формировании HTML. Повторяющиеся события и неподдерживаемые часовые пояса отклоняются с диагностикой.

## Входные данные

Файл iCalendar с событиями `VEVENT` в поддерживаемом подмножестве.

## Выходные данные

HTML-расписание, отсортированное по времени начала, либо диагностическое сообщение.

## Проверка корректности

Проверить сортировку, перенесённые строки, специальные символы HTML, повторяющиеся события и неподдерживаемые часовые пояса.
