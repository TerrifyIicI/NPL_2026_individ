# Задача 5.4. Двусторонняя конвертация Intel HEX ⇄ бинарный образ

**Тема:** Конвертация данных  
**Язык:** Objective-C  
**Ветка:** `5_task_4_objc`

## Постановка задачи

Программа преобразует Intel HEX в бинарный образ с заданными базовым адресом и диапазоном, а также выполняет обратное преобразование с учётом базового адреса. Поддерживаются записи данных, конца файла и расширенного линейного адреса. Проверяются контрольные суммы и пересечения диапазонов, пропуски заполняются байтом `0xFF`. Обратное преобразование сохраняет байты и адреса в выбранном диапазоне, но не обязано воспроизводить исходное разбиение на записи и текстовый вид HEX. Используется GNUstep.

## Входные данные

Файл Intel HEX или BIN, базовый адрес, диапазон и направление преобразования.

## Выходные данные

Файл в целевом формате либо сообщение об ошибке.

## Проверка корректности

Проверить расширенный адрес, пропуски, пересечения, неверную контрольную сумму и сохранение адресов и байтов при обратном преобразовании.
