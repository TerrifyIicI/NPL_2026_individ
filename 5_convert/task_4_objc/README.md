# Задача 5.4 — Конвертер JSON ⇄ NBF с кодированием произвольных объектов через рантайм-интроспекцию

**Тема:** 5. Конвертация данных  
**Язык программирования:** Objective-C  
**Ветка для реализации:** `5_task_4_objc`

## Общая задача темы

Задача темы: конвертация JSON ⇄ NBF, где NBF — собственный бинарный формат с единой спецификацией для всех четырёх программ.

## Постановка задачи

Реализуются две ветки разбора — через штатный сериализатор Foundation и собственным рекурсивным спуском, — а кодировщик NBF обходит произвольный объект через рантайм-интроспекцию, перечисляя свойства класса и разбирая строку их атрибутов, так что кода на каждый класс не требуется вовсе. Это третья точка в главном вопросе темы: Swift описывает соответствие типа и формата протоколом на этапе компиляции, Objective-C — рефлексией в рантайме, Clojure обходится вообще без типов, OCaml кодирует его в типе. Цена рефлексии измеряется напрямую: кодирование миллиона объектов через интроспекцию против прямого кода.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
