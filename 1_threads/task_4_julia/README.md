# Задача 1.4. Параллельное моделирование гравитационного взаимодействия тел

**Тема:** Многопоточность  
**Язык:** Julia  
**Ветка:** `1_task_4_julia`

## Постановка задачи

По начальным координатам, скоростям и массам рассчитывается движение системы тел за заданное число шагов. Вычисление ускорений по состоянию на начало шага распределяется между потоками, после завершения этапа обновляются скорости и координаты. Выводятся конечное состояние системы и её энергия. Для базовой реализации используется фиксированный шаг времени и смягчение гравитационного потенциала при близких расстояниях.

## Входные данные

Начальные координаты, скорости, положительные массы, шаг времени, число шагов, параметр смягчения и число потоков.

## Выходные данные

Конечные координаты и скорости тел, полная энергия системы.

## Проверка корректности

Сравнить результаты при одном и нескольких потоках с числовым допуском; проверить движение двух тел и изменение энергии.
