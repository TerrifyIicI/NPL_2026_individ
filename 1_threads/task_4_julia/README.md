# Задача 1.4 — Параллельный поиск хешей на макросах потоков с замером цены типизации

**Тема:** 1. Многопоточность  
**Язык программирования:** Julia  
**Ветка для реализации:** `1_task_4_julia`

## Общая задача темы

Задача темы: параллельный скан пространства хешей (proof-of-work на FNV-1a 64). Эталоны: Python (threading и multiprocessing), C++ (std::thread + std::atomic).

## Постановка задачи

Та же задача в трёх режимах: @threads, @spawn/fetch и @distributed. Главное измерение — влияние стабильности типов и оптимизаций: один и тот же цикл пишется без аннотаций типов, с явными `UInt64` и с `@inbounds @simd`, три времени сводятся в таблицу, а вывод `@code_warntype` используется для анализа типизации. Отдельно сравниваются первый вызов с учётом JIT-компиляции, повторные вызовы и измеренное время запуска C++.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
