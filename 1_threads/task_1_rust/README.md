# Задача 1.1 — Параллельный поиск хешей на scoped-потоках с доказанной компилятором безопасностью

**Тема:** 1. Многопоточность  
**Язык программирования:** Rust  
**Ветка для реализации:** `1_task_1_rust`

## Общая задача темы

Задача темы: параллельный скан пространства хешей (proof-of-work на FNV-1a 64). Эталоны: Python (threading и multiprocessing), C++ (std::thread + std::atomic).

## Постановка задачи

Диапазон nonce режется на непересекающиеся срезы и раздаётся потокам тремя способами: `thread::scope`, `Arc<AtomicU64>` и `mpsc`-каналы; при одинаковых входных данных результат сравнивается для разного числа потоков, что позволяет проверять корректность синхронизации. Отдельно разбираются три намеренно некорректные версии (`Rc` вместо `Arc`, два одновременных `&mut`, поток с недопустимым временем жизни ссылки): для каждой приводится ошибка компилятора, а затем сравниваются способы выявления аналогичных проблем в Python и C++.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
