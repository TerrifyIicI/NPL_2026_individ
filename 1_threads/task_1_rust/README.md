# Задача 1.1. Параллельный поиск хешей FNV-1a с заданным префиксом

**Тема:** Многопоточность  
**Язык:** Rust  
**Ветка:** `1_task_1_rust`

## Постановка задачи

Заданный диапазон nonce распределяется между scoped-потоками. Каждый поток вычисляет FNV-1a 64 для строк `seed:nonce` и ищет хеши с указанным шестнадцатеричным префиксом. После завершения вычислений объединяются количество найденных значений и минимальный подходящий nonce (или сообщение об отсутствии совпадений).

## Входные данные

Seed, диапазон nonce, префикс хеша и число потоков.

## Выходные данные

Число совпадений и минимальный подходящий nonce либо сообщение об отсутствии совпадений.

## Проверка корректности

Сравнить результаты при одном и нескольких потоках на одинаковом диапазоне; проверить случай без совпадений.
