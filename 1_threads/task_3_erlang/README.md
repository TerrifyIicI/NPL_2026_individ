# Задача 1.3 — Параллельный поиск хешей на легковесных процессах с супервизором

**Тема:** 1. Многопоточность  
**Язык программирования:** Erlang  
**Ветка для реализации:** `1_task_3_erlang`

## Общая задача темы

Задача темы: параллельный скан пространства хешей (proof-of-work на FNV-1a 64). Эталоны: Python (threading и multiprocessing), C++ (std::thread + std::atomic).

## Постановка задачи

Процессы порождаются на каждый кусок диапазона, результаты собираются выборочным `receive` по уникальной ссылке. Измеряется, сколько сущностей способен создать язык: 1 000, 10 000 и 100 000 процессов (в пределах ресурсов системы) в сравнении с потоками ОС в C++ и Python — время создания, пиковая память и память на одну сущность. В режиме `--chaos` рабочий процесс принудительно завершается во время расчёта, супервизор восстанавливает обработку участка, итоговый результат проверяется по эталону.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
