# Задача 1.3. Параллельный поиск простых чисел сегментированным решетом

**Тема:** Многопоточность  
**Язык:** Erlang  
**Ветка:** `1_task_3_erlang`

## Постановка задачи

Координатор распределяет сегменты числового диапазона между рабочими процессами Erlang, выполняющими сегментированное решето Эратосфена. Процессы выполняются параллельно на нескольких планировщиках BEAM при доступности нескольких ядер. Результаты объединяются в количество простых чисел и максимальное найденное число. При сбое рабочего его незавершённый сегмент назначается повторно без двойного учёта результатов.

## Входные данные

Границы целочисленного диапазона, размер сегмента и число рабочих процессов.

## Выходные данные

Количество простых чисел и максимальное простое число либо сообщение об отсутствии простых чисел.

## Проверка корректности

Сравнить с последовательным решетом на небольшом диапазоне; проверить повторное назначение сегмента после сбоя.
