# Задача 1.2. Параллельный рендеринг трёхмерной сцены трассировкой лучей

**Тема:** Многопоточность  
**Язык:** Ada  
**Ветка:** `1_task_2_ada`

## Постановка задачи

Программа строит изображение сцены, содержащей камеру, сферы и источники света. Изображение разбивается на плитки, которые обрабатываются параллельными задачами Ada; учитываются прямое освещение и тени. Результат сохраняется в файл PPM.

## Входные данные

Параметры камеры, сфер, источников света, разрешение изображения и число рабочих задач.

## Выходные данные

Изображение PPM.

## Проверка корректности

Сравнить изображения при последовательной и параллельной обработке; проверить сцены с видимыми тенями и без объектов.
