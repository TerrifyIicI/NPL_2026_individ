# Задача 1.2 — Параллельный поиск хешей на задачах и protected-объектах

**Тема:** 1. Многопоточность  
**Язык программирования:** Ada  
**Ветка для реализации:** `1_task_2_ada`

## Общая задача темы

Задача темы: параллельный скан пространства хешей (proof-of-work на FNV-1a 64). Эталоны: Python (threading и multiprocessing), C++ (std::thread + std::atomic).

## Постановка задачи

Каждый кусок диапазона считает отдельная task с дискриминантом, счётчик и минимум хранит protected object, сбор результатов выполняется через рандеву и барьер входа. Вторая версия обходится вообще без protected-объекта — каждая задача отдаёт результат через собственный entry. Отдельным микробенчмарком сравнивается стоимость 10⁷ инкрементов через protected procedure, через std::atomic в C++ и через threading.Lock в Python.

## Общие условия

- Реализовать основную логику на указанном языке, не используя специализированные библиотеки с готовой реализацией задачи.
- Использовать штатные возможности языка и его платформы для необходимых операций.
- Проверять корректность реализации на тестовых данных. Сравнительные эксперименты и эталоны, указанные в постановке, относятся к этой задаче.
